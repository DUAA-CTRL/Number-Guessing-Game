# 🎀 Number Guessing Game

A fun and interactive number guessing game where players try to guess a secret number between 1 and 100. The game provides hints and tracks the number of attempts.

## ✨ Features

* 🎯 Random number generation (1–100)
* 💭 Too High / Too Low hints
* 💗 Attempt counter
* ✅ Input validation
* 🌸 Cute pink-themed interface
* 🔄 Play Again functionality
* 💻 Python desktop version using Tkinter
* 🌐 HTML version for browser play

## 🛠️ Technologies Used

* Python
* Tkinter
* HTML5
* CSS3
* JavaScript

## ▶️ How to Run

**Python version:**

1. Download `number_guessing.py`.
2. Run `python number_guessing.py` in your terminal.

**HTML version:**

1. Open `index.html` in your browser.
2. Start guessing!
